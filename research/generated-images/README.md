# الصور المولّدة

مراجع مضغوطة للصور المولّدة أصليًا للموقع. **كلها خالية من أي شعار أو
علامة مائية أو حقوق طرف ثالث** — تم التحقّق بصريًا من كل واحدة.

| الملف | الوصف |
|---|---|
| `hero_new-ref` | بطل عرضي 16:9 — دلّة وفناجيل وتمور على رخام |
| `hero_b-ref` | بطل عرضي بديل — مجلس فخم |
| `tall_a-ref` | 🔑 **بطل طولي 9:16** للجوال |
| `tall_b-ref` | 🔑 بطل طولي بديل للجوال |

## 🔑 لماذا نسخ طولية؟
لأن صورة 16:9 داخل إطار هاتف 390×926 لا يبقى منها إلا شريط رأسي ضيّق —
والموضوع يقع خارجه. هذا كان السبب الحقيقي لشكوى «صورة ما تعرفها شي»، لا
جودة الصورة. التفصيل الكامل في `../../docs/07-decisions.md` قرار 3.

**الملفات المستخدمة فعلًا في الموقع** في `public/static/img/` بثلاثة
مقاسات WebP لكل صورة. هذه هنا **مراجع للتوثيق** فقط.

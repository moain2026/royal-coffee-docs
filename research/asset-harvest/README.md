# جرد الأصول

بيانات نصية فقط (لا ملفات ثنائية) عن أصول المنافسين — لقياس حجم مكتبتهم
البصرية وبنية موقعهم.

| الملف | المحتوى |
|---|---|
| `inv.json` | الجرد الكامل |
| `manifest.json` | بيان الأصول |
| `assets.json` | قائمة الأصول المكتشفة |
| `sheets.json` | ملفات CSS المكتشفة |
| `sizes.json` | مقاسات الصور |
| `whitelist.json` | ما اجتاز الفرز |
| `keif_imgs.txt` | قائمة روابط صور |
| خرائط المواقع + خرائط الصور + `robots.txt` | بنية الفهرسة عندهم |
| `fetch.sh` | سكربت الجمع |

## ⚠️ لماذا لا توجد صور هنا؟
الملفات الثنائية المُنزَّلة (≈62 ميجابايت) **حُذفت عن قصد**: لا حقوق
استخدام لها، ولا قيمة توثيقية فوق ما تحمله البيانات النصية. صور الموقع
المنشور كلها **مولّدة أصليًا** — انظر `../generated-images/`.

## 🔴 لماذا `under-44px: 2` ليس خطأً؟
الزرّان هما زرّا القائمة السفلية بارتفاع **36 بكسل** — مخالفة **مقصودة**
للمعيار بناءً على طلب العميل الحرفي «صغرهم يا غالي». مُوثَّقة كمقايضة
مقبولة في `../docs/07-decisions.md` قرار 6.

## 🔴 لم يُقَس
**Lighthouse / Core Web Vitals لم تُشغَّل نهائيًا.** ما قيسناه: الأحجام،
تكلفة الحركة، الفائض، طول العناوين. انظر `../docs/08-roadmap.md`.
